# 🚀 Guide de Configuration du Dépôt GitHub

Ce guide fournit toutes les métadonnées et instructions pour configurer la page d'accueil de votre dépôt GitHub **[f1-telemetry](https://github.com/Klemz-696/f1-telemetry)** de façon professionnelle.

---

## 🏷️ 1. Section "About" (En-tête du Dépôt)

Sur la page de votre dépôt GitHub (`https://github.com/Klemz-696/f1-telemetry`), cliquez sur l'icône ⚙️ **Settings** (à droite de "About") et renseignez :

### **Description (Anglais - Recommandé pour visibilité internationale) :**
```text
🏎️ High-Performance Formula 1 Live Telemetry, Timing Tower, 2D/3D Track Map, Simulation Engine & Broadcast Overlays for Season 2026. Powered by FastAPI, InfluxDB, Node.js Proxy & Vanilla JS.
```

### **Description alternative (Français) :**
```text
🏎️ Hub de télémétrie F1 temps réel, tour de chronométrage, carte 2D/3D, moteur de simulation et overlays OBS pour la saison 2026. Stack FastAPI, InfluxDB, Docker et Vanilla JS.
```

### **Website :**
```text
https://github.com/Klemz-696/f1-telemetry
```
*(ou l'URL de votre portfolio si hébergé en ligne)*

## 📸 4. Image d'Aperçu Social (Social Preview)

Pour ajouter une vignette attrayante lorsque le lien GitHub est partagé sur LinkedIn, Discord ou Twitter :
1. Allez dans **Settings** du dépôt GitHub.
2. Descendez jusqu'à **Social preview**.
3. Cliquez sur **Edit** -> **Upload an image**.
4. Déposez une capture d'écran du tableau de bord F1 (1280x640 px recommandé).
