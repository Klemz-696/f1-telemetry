🏁 Guide d'utilisation
Lancez docker-compose up depuis le dossier du projet. Le proxy Node.js démarre sur le port 3001. Vérifiez que les variables dans .env sont correctes (INFLUX, OpenF1…).
Sélectionnez 📡 DIRECT dans le menu en haut à droite de la page Live. Le badge passe en vert quand la connexion WebSocket est établie. ⚠ Actuellement indisponible : la F1 a bloqué les IP des flux temps réel.
La dernière session est chargée depuis le cache local. C'est le mode par défaut. Les données de timing, carte et direction de course sont disponibles hors-ligne. Utile pour revoir une session précédente.
Des données fictives reproduisent une course complète en temps réel. Idéal pour tester l'interface, faire des démos, ou découvrir les fonctionnalités du dashboard sans session live disponible.
Activez le Mode édition ci-dessus. Vous pouvez ensuite glisser les panneaux par leur bandeau supérieur, redimensionner depuis le coin ⤡, et choisir la visibilité de chaque panneau. Sauvegardez via le bouton en bas de page.
Il s'affiche uniquement sur la page Live pendant un week-end de GP. Il ouvre un panneau flottant avec les horaires de toutes les séances du week-end en cours.
La Formule 1 a mis en place des restrictions d'accès IP sur ses flux de télémétrie en temps réel (OpenF1 API). Le mode direct ne fonctionne plus jusqu'à ce que ces restrictions soient levées ou contournées. Les modes Archive, Simulation et toutes les autres fonctionnalités du site restent disponibles.
